Cara Deploy Game Ini ke GitHub Pages Gratis!

Hanya butuh 3 menit tanpa perlu server paid/install software.

Langkah 1: Simpan Kode Game

Copy seluruh kode file HTML ini dan simpan di komputer kamu dengan nama file index.html.

Langkah 2: Buat Repository di GitHub
  1. Buka halaman github.com lalu buat akun / login.
  2. Klik tombol hijau "New Repository".
  3. Beri nama repository (misal: kuliner-game-tycoon).
  4. Pastikan centang opsi Public, lalu klik Create repository.
Langkah 3: Upload File index.html

Di dalam repository baru tersebut, klik link "uploading an existing file". Drag and drop file index.html kamu, lalu klik tombol hijau Commit Changes.

Langkah 4: Aktifkan GitHub Pages
  1. Masuk ke menu tab Settings di repository tersebut.
  2. Klik menu Pages di sidebar sebelah kiri.
  3. Pada bagian Build and deployment -> Branch, ubah dari None menjadi main (atau master) lalu klik Save.
  4. Tunggu 1-2 menit, lalu refresh halaman. Kamu akan mendapatkan URL link live game kamu! 🎉
